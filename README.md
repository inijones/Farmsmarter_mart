# Farmsmarter Mart

A mobile-first 3D farm-to-market game. Grow tomatoes, carrots, and corn, collect eggs and milk, carry them into Farmsmarter Mart, and lay them on the shelves. Shoppers pay in naira. Hire a seller so checkout keeps going while you farm.

The world is built from original low-poly shapes. It follows the elevated three-quarter view, open shop floor, crop beds, and shelf counters shown in the design references.

## Play

```bash
npm install
npm run dev -- --host 0.0.0.0
```

Open the local URL on your computer. On a phone sharing the same Wi-Fi, open the network URL Vite prints.

- Drag the joystick (or use WASD) to walk.
- The action button changes with what you are near: harvest, plant, collect, stock, or hire.
- Space or E does the same thing on a keyboard.
- Progress is saved in this browser and restored on refresh.

```bash
npm run build
npm run preview -- --host 0.0.0.0
```
